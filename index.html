Research

Model, quantify, control.

My work sits at the intersection of three things: modeling a system, measuring how far the model can be trusted, and using it to control the system.

  1. 01

    System modeling

    Learn how a system behaves from data, with physics built into the model so it holds up when data is scarce.

  2. 02

    Uncertainty quantification

    Measure how far the model can be trusted, so a controller knows when it is working outside what the model has seen.

  3. 03

    Optimal control

    Use the model to act: controllers that plan ahead, adapt online, and run on real hardware.
